# GABBY 쇼핑몰 (Next.js)

Next.js App Router + TypeScript로 만든 패션 쇼핑몰 화면 모음입니다.
상품명, 가격, 이미지 등은 자리표시자이고, 로그인·장바구니·결제 같은 동작은 아직 없는 화면 디자인입니다.

## 실행

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # 배포용 빌드
```

## Vercel 배포

저장소를 Import하면 Framework Preset이 `Next.js`로 자동 선택됩니다. 별도 설정은 필요 없습니다.
이전 HTML 파일(`index.html` 등)이 저장소 맨 위에 남아 있다면 삭제해 주세요.

## DB 연결 (Neon, Postgres)

카테고리 목록(`/list/*`)은 DB에서 상품을 읽습니다. DB가 연결되기 전에는 `lib/lists.ts`의 샘플 데이터를 보여줍니다.

1. Vercel 프로젝트의 Storage(또는 Marketplace)에서 **Neon**을 설치하고 이 프로젝트에 연결합니다.
   `DATABASE_URL`, `DATABASE_URL_UNPOOLED`가 환경 변수로 자동 등록됩니다.
2. 내 컴퓨터에서 `.env.example`을 `.env`로 복사하고, Vercel의 Settings → Environment Variables 또는 Neon 콘솔(Connect)에서 값을 복사해 채웁니다.
3. 터미널에서 실행합니다.

```bash
npm install
npm run db:push   # 테이블 생성
npm run db:seed   # 샘플 상품 넣기 (다시 실행하면 상품이 초기화됩니다)
```

4. 로그인용 테이블(`User` 회원, `Session` 로그인 상태)도 같은 `db:push`로 함께 만들어집니다.
5. 회원가입(`/signup`)과 로그인(`/login`)이 동작합니다. 비밀번호는 암호화해서 저장하고, 로그인하면 `Session` 테이블과 쿠키로 로그인 상태를 유지합니다. 로그인하면 헤더에 이름과 LOGOUT이 보입니다.
6. 로그인이 필요한 화면은 아래 "로그인이 필요한 화면" 항목을 참고하세요.
7. GitHub에 올리면 Vercel이 자동 배포합니다. `.env`는 올리지 마세요.

연결한 DB가 배포(운영)에서도 같은 DB라면, 위 명령은 그 DB에 바로 적용됩니다.

## 주문 테이블

구매 내역을 저장하는 `Order`(주문)와 `OrderItem`(주문 상품) 테이블이 `prisma/schema.prisma`에 정의돼 있습니다.
SQL Editor로 테이블을 직접 만들어 쓰는 경우 `prisma/add-orders.sql`을 한 번 실행하세요. (`npm run db:push`를 쓴다면 자동으로 만들어집니다.)
주문/결제 화면의 PAY 버튼을 누르면 이 테이블에 저장되고, 주문 완료·주문 상세·마이페이지(주문 내역)에서 보여줍니다.
실제 결제(PG)는 연결하지 않았고, 장바구니도 아직 DB에 저장되지 않아서 주문/결제 화면에 보이는 상품 2개(`lib/orders.ts`의 `CHECKOUT_ITEMS`)가 주문됩니다. 주문은 '주문 접수' 상태로 저장됩니다.

## 로그인이 필요한 화면

마이페이지, 주문 내역/상세, 관심 상품, 적립금, 쿠폰, 회원 정보 수정, 취소/반품/교환, 주문/결제, 주문 완료, 후기·문의 작성은 로그인한 회원만 볼 수 있습니다.
로그인하지 않고 들어가면 `/login`으로 이동하고, 로그인하면 원래 가려던 화면으로 돌아옵니다. 장바구니는 로그인 없이 볼 수 있습니다.

- 1차 확인(로그인 쿠키가 있는지): `middleware.ts`의 `PROTECTED` 목록
- 2차 확인(DB 세션이 유효한지): 각 보호 화면 맨 위의 `await requireUser("/주소")`
- 화면을 새로 보호하려면 두 곳에 모두 주소를 추가하세요.
- DB가 연결되기 전에는 로그인할 수 없으므로 이 화면들을 볼 수 없습니다.

## 보안·주문 기능 (로그인 제한, 주소 검색, 주문 알림, 비회원 주문)

- **로그인 시도 제한:** 같은 아이디로 5번, 같은 접속지에서 20번 틀리면 15분 동안 로그인을 막습니다. 아이디 찾기(10분에 10번), 비밀번호 재설정 메일 요청(접속지 1시간 5번, 이메일 1시간 3번), 비회원 주문 조회(10분에 10번), 비회원 주문(1시간에 10번)도 제한합니다. 같은 아이디를 일부러 틀려 잠글 수 있다는 점은 이런 방식의 한계입니다(관리자 계정 포함).
- **주소 검색:** 주문/결제에서 `주소 검색`을 누르면 카카오(다음) 우편번호 검색이 뜨고, 우편번호와 주소가 채워집니다. 별도 가입이나 키가 필요 없습니다. 검색을 불러오지 못하면 주소를 직접 입력할 수 있습니다.
- **주문 알림 메일:** 주문 접수(고객), 발송 시작·배송 완료·취소(관리자가 주문 상태를 바꿀 때) 때 주문자 이메일로 알려줍니다. 비밀번호 찾기와 같은 메일 서비스(Resend)를 씁니다: 환경 변수 `RESEND_API_KEY`, `EMAIL_FROM`(필수), `SITE_URL`(메일 링크용, 권장), `ADMIN_EMAIL`(새 주문을 관리자에게도 알릴 때). 설정하지 않으면 메일만 건너뛰고 주문은 정상 처리됩니다.
- **비회원 주문:** 상품 상세의 `BUY NOW`로 로그인 없이 주문할 수 있습니다(장바구니·쿠폰·적립금·관심 상품·후기·문의는 로그인 필요). 주문 완료 화면과 메일의 링크(비밀 토큰 포함), 또는 `/order-lookup`에서 주문번호+휴대전화로 조회합니다. 비회원 주문의 취소·반품·교환은 고객센터로 문의하는 방식입니다.
- 이 기능들을 쓰려면 새 코드를 올린 뒤 **관리자 > DB 설정 > 테이블 만들기**를 한 번 눌러 주세요.

## 게시판·회원 기능·쿠폰/적립금 (DB 연결)

- **후기:** 구매한 상품(취소하지 않은 주문)만 상품당 1개 작성. 상품 상세와 후기 화면에 평균 별점과 후기가 보입니다. 관리자가 삭제할 수 있습니다.
- **Q&A:** 로그인한 회원이 작성(비밀글 가능), 관리자가 답변. 비밀글은 작성자와 관리자만 봅니다.
- **공지사항:** 관리자가 작성·수정·삭제, 상단 고정 가능.
- **검색:** 상품 이름·설명으로 검색합니다. 메인 화면의 상품 줄도 DB 상품을 보여줍니다(상품이 없으면 샘플).
- **아이디 찾기:** 이름+이메일이 맞으면 아이디 일부를 가려서 보여줍니다.
- **비밀번호 찾기:** 이메일로 재설정 링크(1시간, 1회용)를 보냅니다. 메일 발송 서비스(Resend)가 필요합니다. 환경 변수 `RESEND_API_KEY`, `EMAIL_FROM`(보내는 주소), 선택 `SITE_URL`(예: https://내사이트.com)을 Vercel에 넣으세요. 설정하지 않으면 "이메일 발송 서비스가 아직 연결되지 않았어요"라고 안내합니다.
- **회원 정보 수정:** 이름·이메일·전화·마케팅 동의 수정, 비밀번호 변경.
- **취소·반품·교환:** 주문 상세에서 신청(취소는 배송 전, 반품·교환은 배송 시작 후). 관리자가 처리 상태를 바꾸고, 취소·반품을 완료하면 주문이 취소 처리되어 재고·사용한 적립금·쿠폰이 되돌아갑니다.
- **쿠폰:** 관리자가 쿠폰(정률/정액, 최소 주문 금액, 만료일)을 만들고 번호를 알려주면, 고객이 쿠폰 화면에서 번호를 등록해 주문/결제에서 1개 사용합니다.
- **적립금:** 배송 완료 시 결제 금액(배송비 제외)의 1%(`lib/orders.ts`의 `POINT_RATE`)가 적립되고, 주문/결제에서 사용할 수 있습니다. 주문을 취소하면 사용한 적립금은 돌려주고 받은 적립금은 회수합니다.

**테이블 만들기:** 코드를 올린 뒤 관리자로 로그인해서 **관리자 > DB 설정**에서 `테이블 만들기` 버튼을 한 번 누르세요. 필요한 테이블과 컬럼을 한 번에, 이미 있는 것은 건너뛰며 만들어 줍니다. (SQL Editor에서 직접 실행할 필요가 없습니다.)

## 관심 상품과 재고

**관심 상품:** 상품 상세의 `♡ WISHLIST`를 누르면 로그인한 회원의 관심 상품에 담기고(다시 누르면 빠짐), 마이페이지의 관심 상품(`/wishlist`)에서 보고 삭제할 수 있습니다.
**재고:** 관리자가 상품 추가·수정 화면에서 사이즈별(S/M/L) 재고를 입력합니다. 칸을 비우면 그 사이즈는 재고를 관리하지 않는 것(무제한)이고, 0이면 품절입니다.
- 품절 사이즈는 상세에서 선택할 수 없고, 모든 사이즈가 품절이면 `SOLD OUT`으로 표시됩니다. 재고가 3개 이하면 `(N개 남음)`이 보입니다.
- 장바구니에 담을 때 재고를 넘기면 가능한 만큼만 담기고, 담은 뒤 재고가 줄었다면 장바구니에서 안내하며 주문을 막습니다.
- 주문이 저장될 때 재고가 자동으로 줄어들고(재고가 모자라면 주문이 거절됨), 관리자가 주문을 **취소**하면 재고가 되돌아옵니다. 취소한 주문은 상태를 되돌릴 수 없습니다.
- 관리자 대시보드에 품절·재고 부족 개수가, 상품 관리 목록에 사이즈별 재고(∞는 무제한)가 보입니다.
**테이블:** 새 코드를 올리기 전에 `prisma/wishlist-stock.sql`을 Neon SQL Editor에서 한 번 실행하세요.

## 상품 상세 페이지 (/product/상품번호)

관리자가 추가한 상품을 목록에서 누르면 그 상품의 상세 페이지(`/product/상품번호`)가 열립니다. 이름, 가격, 할인, 이미지, 설명은 DB 값입니다.
상세의 `BUY NOW`를 누르면 그 상품(사이즈, 수량 포함)이 주문/결제 화면에 올라가고, 결제하면 `OrderItem`에 그 상품이 저장됩니다. 가격은 서버가 DB에서 다시 확인합니다.
`ADD TO CART`를 누르면 로그인한 회원의 장바구니(`CartItem` 테이블)에 담기고, 장바구니 화면(`/cart`)에서 수량 변경, 삭제, 전체 주문(`ORDER`)을 할 수 있습니다. 같은 상품도 사이즈가 다르면 다른 줄이고, 한 줄에 최대 10개까지 담깁니다. 장바구니에서 주문하면 주문이 저장되면서 장바구니가 비워집니다. 샘플 상품(DB에 없는 상품)은 장바구니에 담을 수 없습니다. 장바구니는 로그인해야 쓸 수 있습니다.
**장바구니 테이블:** 새 코드를 올리기 전에 `prisma/cart-item.sql`을 Neon SQL Editor에서 한 번 실행하세요.

## 이미지 파일 올리기 (DB에 저장)

상품 추가·수정 화면에서 이미지 파일(JPG, PNG, WEBP, GIF)을 올리면 DB(`ProductImage` 테이블)에 저장되고, 이미지 주소 칸에 `/api/product-image/이미지번호`가 자동으로 채워집니다. 별도 파일 저장소는 필요 없습니다.
주소를 직접 입력하면, 입력한 주소의 이미지가 실제로 열리는지 미리보기에서 바로 확인해 줍니다. 열리지 않으면 저장할 수 없습니다.

**연결 방법 (한 번만)**
1. 새 코드를 올리기 **전에** Neon SQL Editor에서 `prisma/product-image-table.sql`을 한 번 실행하세요. (`ProductImage` 테이블이 만들어집니다.)
2. 코드를 GitHub에 올리면 Vercel이 배포합니다.

**동작과 제한**
- 큰 이미지는 올리기 전에 브라우저에서 자동으로 줄입니다(가로 1200px 이하, JPEG). 움직이는 GIF와 이미 작은 파일은 그대로 올립니다.
- 서버는 줄인 뒤 2MB까지만 받습니다. 관리자만 올릴 수 있고, 파일 앞부분으로 실제 이미지인지 확인합니다.
- 이미지는 DB 용량을 씁니다. 무료 DB는 용량이 작으니 사진을 아주 많이 올릴 계획이라면 별도 파일 저장소(예: Vercel Blob)를 고려하세요.
- 상품을 삭제하거나 이미지를 다른 것으로 바꾸면 이전 이미지는 DB에서 함께 지워집니다. 올리기만 하고 저장하지 않은 이미지는 DB에 남습니다.

## 관리자 페이지 (/admin)

관리자 계정으로 로그인하면 `/admin`으로 이동합니다. 헤더에도 `ADMIN` 링크가 생깁니다.

| 화면 | 기능 |
|---|---|
| 대시보드 | 오늘 주문, 배송 처리 대기, 전체 주문, 회원 수, 주문 금액 합계, 최근 주문 |
| 주문 / 배송 관리 | 주문 목록(받는 사람·연락처·배송지), 상태별 필터, 검색, 주문 상세, 주문 상태 변경, 택배사·운송장 입력 |
| 회원 관리 | 회원 목록과 검색 (보기 전용), 회원별 주문 수 |
| 상품 관리 | 상품 목록, 상품 추가(`/admin/products/new`), 상품 수정(카테고리, 이름, 가격, 할인, 순서, 배경색, 이미지 주소, 설명, 미리보기), 삭제. 카테고리 목록과 상품 상세에 바로 반영 |
| 관리자 계정 | 비밀번호 변경 |

**상품 컬럼 추가:** 새 코드를 올리기 전에 Neon SQL Editor에서 `prisma/product-image.sql`(이미지 주소)과 `prisma/product-description.sql`(상품 설명)을 한 번씩 실행하세요.

(이전 안내) **상품 이미지 컬럼 추가:** 상품 추가 페이지의 이미지 주소를 쓰려면, 코드를 올리기 전에 `prisma/product-image.sql`을 Neon SQL Editor에서 한 번 실행하세요.

**설정 순서 (중요)**
1. 새 코드를 올리기 **전에** Neon SQL Editor에서 `prisma/admin-setup.sql`을 한 번 실행하세요. 컬럼 3개를 추가하고 관리자 계정(아이디 `admin`, 비밀번호 `admin`)을 만듭니다.
2. 코드를 GitHub에 올리면 Vercel이 배포합니다.
3. `/login`에서 `admin` / `admin`으로 로그인한 뒤, **바로 관리자 > 관리자 계정에서 비밀번호를 바꾸세요.**

**주의**
- `admin`/`admin`은 누구나 추측할 수 있는 값입니다. 공개된 주소에서는 고객의 이름·연락처·주소가 노출될 수 있으니 반드시 바꾸세요.
- 관리자 여부는 DB의 `User.role`(`ADMIN`)로 판단합니다. 모든 관리자 화면과 관리자 동작은 서버에서 한 번 더 확인합니다.
- 로그인 시도 횟수 제한이 없습니다. 운영 전에는 추가하는 것을 권장합니다.
